## 4. 指标口径（重要，防止误读）

- **二值口径**：`calculate_all_metrics` 只接受 0/1 二值掩膜。本模型输出 3 类（0 背景 / 1 肾脏 / 2 肿瘤），模块12 已把**肿瘤类**（`pred==2`）单独二值化再评估；要评估肾脏，把 `== 2` 改成 `== 1`。
- **空掩膜规则**：预测与标签都为空 → Dice=1、IoU=1（视为完美）；一边为空一边非空 → 0。CT 切片里肿瘤通常只占少数，很多切片"双空"，所以 Dice 与 IoU 数值会非常接近——这是正常现象，不是 bug。
- **熵指标（已真实）**：人员3 的 `mc_predict` 已交付并接入（模块9.5/10），熵图从 `samples/sample_%04d.npz` 读取真实值；`tumor_mean_entropy / rejection_rate / coverage / selective_accuracy` 均为真实结果，不再是占位。
- **像素准确率会被背景主导**（肿瘤占比很小），分数接近 1 不代表分割好，务必以 Dice / IoU 为准。


### 4.1 每个测试样本的数组产物（人员4 读取，非 .pth）

模块13 每个实验的 `samples/` 目录下，**每个测试样本**一个 `sample_%04d.npz` 数组文件（`.pth` 仅用于保存模型权重，与样本输出无关）：

| 字段 | shape | 含义 |
|---|---|---|
| `mean` | (3,H,W) | MC-Dropout 平均概率图（softmax，0/1/2 三类） |
| `pred` | (H,W) | `mean` 的 argmax 类别（0=背景/1=肾脏/2=肿瘤），与 `label` 同口径 |
| `pred_binary` | (H,W) | 肿瘤二值（`pred==2`），0/1 |
| `variance` | (H,W) | 逐像素方差（跨类别平均） |
| `entropy` | (H,W) | 逐像素熵（由 `mean` 概率计算） |
| `label` | (H,W) | 真实 3 类 mask |

读取方式：`load_mc_outputs_from_npz(npz_path)`（notebook 模块9.5，返回 dict 含以上全部字段）；指标库 `src/metrics/unified_metrics.py` 的 `load_npz_sample` 已同步兼容新/旧字段。
