## 3. 使用方法
### 3.1 生成 manifest（在 E:\大创 或 Kaggle 上）
```bash
# 本地 4 病例快速验证
python downsample.py --data-root E:/大创/kits19_small --out-dir E:/大创/experiments \
    --fractions 0.10,0.20 --seed 42 --train-ratio 0.5 --val-ratio 0.25 --max-cases 4

# Kaggle 全量
python downsample.py --data-root /kaggle/input/datasets/user123454321/kits19-1 \
    --out-dir /kaggle/working/experiments --fractions 0.10,0.20 --seed 42
```
产出：`experiments/data10pct/manifest.json`、`experiments/data20pct/manifest.json`。

### 3.2 实验模式跑主代码（VSCode / Kaggle）
- **VSCode（推荐做法）**：打开 `总模型代码进行中.ipynb`，把**模块4.5** cell 顶部的
  ```python
  EXPERIMENT_MANIFEST = os.environ.get("EXPERIMENT_MANIFEST", "").strip()
  ```
  改成绝对路径赋值：
  ```python
  EXPERIMENT_MANIFEST = r"E:\大创\experiments\data10pct\manifest.json"
  ```
  然后选内核（本地用 `E:\python`）→ `Kernel → Restart Kernel` → 运行全部。
- 注意：**不建议**在 VSCode 集成终端里 `$env:EXPERIMENT_MANIFEST=...` 再点 Run All——Jupyter 内核不继承终端环境变量，直接改 cell 最可靠。
- Kaggle：在模块4.5 顶部直接给 `EXPERIMENT_MANIFEST` 赋值（如 `/kaggle/working/experiments/data10pct/manifest.json`）。
- 不设置该变量 = 原默认模式（全量或本地快速验证），行为与之前完全一致。

## 4. 口径与注意事项

- **测试集冻结**：test 始终取全量划分的测试病例，各比例间完全一致，不做降采样。
- **seed=42 固定**，manifest 里记录 seed 与划分比例（`train_ratio/val_ratio/test_ratio/max_cases`），可完全复现。
- 按病例划分，禁止同一病例切片跨集合（避免数据泄漏）。
- 实验模式下训练集 `drop_last=False`（小样本只有 1-2 例时保留唯一批次）。
- **修改划分逻辑时，必须同步 notebook 模块4 与 `downsample.py` 两处**（当前刻意保持逐行一致）。
- 本地 4 病例的 10%/20% 实验都只剩 1 个训练例，只能验证流程，**真实对比必须在 Kaggle 全量上跑**。

### 5.1 人员3——贝叶斯 mc_predict
- **病例划分**：直接读 manifest 的 `train_cases/val_cases/test_cases`（病例名清单），不要自己再划分。本地：`E:\大创\experiments\data10pct\manifest.json`；Kaggle：`/kaggle/working/experiments/data10pct/manifest.json`。
- **契约 A 输出格式**：`mc_predict` 输出 `mean / variance / entropy` 三个通道的 npz + `meta.json`（含病例、切片、类别说明）。
- **接入**：交付后替换 notebook 模块12 里的熵图占位：
  ```python
  # 现在（占位）：entropy_map = np.zeros_like(pred_tumor)
  # 改成（真实）：entropy_map = np.load("mc_predict输出.npz")["entropy"]  # 按 meta.json 对齐切片顺序
  ```
  替换后模块12/13 会自动产出真实熵指标，无需再改其他模块。

### 5.2 人员4——统计检验
- **指标来源**：每个实验目录的 `metrics.json`（契约 D）。本地：`E:\大创\experiments\data10pct|data20pct\`；Kaggle：`/kaggle/working/experiments/...`。
- **批量读取示例**：
  ```python

  ```
- **统计检验输入**：baseline（全量）+ 10% + 20% 各实验的 `metrics.json`；不要自己重新划分数据。
- **注意**：熵相关字段在人员3 交付前是占位值（0/0/1/dice），检验时先只用 `dice/iou/pixel_acc`，等真实熵图到位再纳入熵指标。
