## 3. 产物规范（重点，契约 D）

运行完成后，三个实验目录结构完全一致：

```
experiments/
├── data10pct/
│   ├── manifest.json           # 病例划分（契约 C，唯一口径）
│   ├── best_unet.pth           # 最优模型权重
│   ├── training_curves.png     # 训练/验证曲线

│   └── samples/                # 契约 A：每个测试样本一个 npz + json
│       ├── sample_0001.npz     # 字段：mean / variance / entropy / pred / label
│       ├── sample_0001.json    # 样本元信息（tumor_avg_entropy、n_samples 等）
│       └── ...
├── data20pct/                  # 结构同上
└── datafull/                   # 结构同上（全量基准）
```

- **位置**：Kaggle 在 `/kaggle/working/experiments/`；本地在 `E:\大创\output\experiments\`。
- 所有产物都在实验目录内部，**禁止散落到 experiments 外层**。
- 10%/20% 只降采样训练集；**测试集冻结**：三个实验测试集完全一致，对比才公平。
- manifest 记录 seed（=42）/ 划分比例 / 病例清单，可完全复现。
- `samples/` 编号 `idx+1` 与测试集顺序一一对应，统计检验按编号直接对齐。

## 4. 内部机制（给想改代码的人）

- 模块1.5：Kaggle 自动 clone 仓库并 chdir；若 10%/20% manifest 缺失，自动调用 `downsample.py` 生成。
- 模块4.5：`setup_experiment(exp_name)` 读 manifest 建 dataset + loader，并把 `cfg.OUTPUT_DIR` 指向实验目录；datafull 的 manifest 由该模块用与 downsample.py 相同口径（同 seed 同比例）在函数内独立重算生成，避免被外部循环变量污染。
- 模块9.5：`mc_predict` 输出落 `samples/`；模块10 从 samples 读真实熵图计算契约 B 指标，缺失时才回退全 0 占位并打印提示。
- 模块13：`for exp in [data10pct, data20pct, datafull]`：训练 → MC → 评估 → 绘图 → `metrics.json`，最后打印汇总表。

## 5. 角色对接

### 5.1 贝叶斯推理（M1 负责人）
- 病例划分：直接读各实验目录 `manifest.json` 的 `train_cases / val_cases / test_cases`，不要自己划分。
- 输出格式：已由模块9.5 内置为 `samples/sample_%04d.npz`（mean / variance / entropy / pred / label）+ 同名 json；如需调 MC 次数改 `MC_N_SAMPLES` 即可。
- 后续：接入真实贝叶斯层（Dropout 变体等）后，替换模块9.5 的模型前向即可，产物路径与结构不用变。

### 5.2 统计检验（评估工具负责人）
- 指标来源：每个实验目录的 `metrics.json`（含 dice / iou / pixel_acc / 熵指标 / 最优验证指标）。
- 批量读取示例：
  ```python
  import json, glob
  for p in sorted(glob.glob(r"E:\大创\output\experiments\*\metrics.json")):
      m = json.load(open(p, encoding="utf-8"))
      print(m["experiment"], m["n_train_cases"], m["best_val_dice"], m["metrics"])
  ```
- Risk-Coverage / 选择性预测：用 `samples/sample_%04d.npz` 的 `entropy` 与 `pred` / `label` 逐样本对齐做拒识曲线；`evaluation_metrics.csv` 是模块10 已算好的 7 项汇总。
- 统计检验必须用 Kaggle 正式实验的产物，**不要用本地 4 例冒烟结果做统计**。

### 5.3 论文 / 结题
- 指标统一取 `metrics.json` / `evaluation_metrics.csv`；图直接用实验目录下的两张 png。
- "同一划分、多比例对比"用 10% / 20% / 全量三组 `metrics.json` 出表。
